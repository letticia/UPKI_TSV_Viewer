# 電子証明書 TSV Viewer

電子証明書自動発行支援システム（ACME情報およびサーバ・クライアント証明書情報）から一括ダウンロードしたTSVファイルを、ブラウザ上で表示・検索・フィルタリングするためのクライアントサイドWebアプリケーションです。  
登録担当者向けのツールです。  
電子証明書の発行/更新/失効申請用のTSVファイルについては、[TSVツール](https://certs.nii.ac.jp/tsv-tool/)をご利用ください。  

## 特徴

- **完全クライアントサイド動作**: サーバー環境は不要です。`index.html` をブラウザで開くだけで利用できます。ファイルの内容は外部に送信されないため、ローカル環境で安全にデータを閲覧できます。
- **大量件数対応（2〜10万件規模）**: Web Worker による非同期パースと Pre-computed Search Index により、2〜3万件はもちろん、将来的に10万件規模のTSVファイルでも快適に動作します。ファイルの読み込み・解析中もUIはブロックされません。
- **ドラッグ＆ドロップとレイアウト自動縮小**: 画面へのドラッグ＆ドロップによるファイル読み込みに対応しています。ドラッグ中は枠線やアイコンのアニメーションが表示されます。ファイル読み込み完了後は、テーブルの閲覧領域を確保するため、ドロップゾーンの高さが自動的に縮小します。
- **Shift_JIS 自動デコード**: ダウンロードされたShift_JIS形式のTSVファイルを自動的にUTF-8にデコードし、文字化けを防ぎます。
- **ステータス値の自動マッピングとカラーバッジ化**: 生データの数値（状態コードやプロファイルIDなど）を「1:ACME作成」や「3:サーバ証明書」といったテキストに自動変換し、状態（成功、警告、エラー、進行中など）に応じて色分けされたバッジとして表示します。

## テーブル機能

- **高速フリーワード検索と列の絞り込み**: 読み込み時に全行の検索インデックスを事前生成するため、2〜3万件でも50ms以下で検索結果を返します。変換後のテキスト（コードマッピング展開済み）を含め、すべての列を横断して検索が可能です。特定の列を指定して検索範囲を絞り込むこともできます。
- **ページネーション**: 大量件数でも快適に閲覧できるよう、1ページあたりの表示件数を「200件」「100件」から選択できます。テーブル下部のナビゲーターで前後のページに移動できます。
- **テーブル列のソート**: 各列のヘッダーをクリックすることで、日付、数値、文字列を自動判別し、昇順・降順で並べ替えることができます。絞り込み結果の中でのみ並べ替えるため、元データは変更されません。
- **件数表示**: フィルタリングされた件数を「表示中: X 件 / 全 Y 件」として表示します。
- **クリックコピー**: シリアル番号、DN、FQDN、申請IDなどのセルは、ホバー時に表示されるコピー用ボタン（📋）をクリックすることで、クリップボードにコピーできます。
- **クイックフィルター**: 「最終更新日（1週間/1ヶ月/3ヶ月以内）」や「有効期限（1週間/30日以内）」など、指定した日付範囲で行を絞り込むことができます。
- **表示結果のエクスポート**: 検索・フィルタリングした結果のみを抽出し、Excelなどで開けるTSVファイルとしてダウンロード（エクスポート）できます。
- **列の表示/非表示トグル**: 必要な列だけを選択して表示することが可能です。
- **長文データの表示とダウンロード**: 「CSR」や「発行・更新申請-証明書」といったデータ量の多いセルは、「内容を表示」ボタンでモーダル表示できるほか、PEM形式ファイル（.csr や .cer）として適切なファイル名でダウンロードできます（モーダル内にもコピー機能があります）。

## UI / デザイン

- **テーマ切り替え**: 外部ライブラリを使用しない Vanilla CSS で構成されています。標準の「ライトテーマ」と「ダークモード（グラスモーフィズム）」を画面右上のボタンから切り替えることができます。
- **ローディング表示**: ファイルの解析中はスピナーオーバーレイを表示し、処理の進行状況を確認できます。

## 使い方

1. リポジトリをクローン、またはダウンロードして解凍します。
2. フォルダ内にある `index.html` をお使いのWebブラウザ（Google Chrome, Firefox, Edge, Safari等）で開きます。
3. 画面の指定エリアに、システムからダウンロードした `.tsv` ファイルをドラッグ＆ドロップするか、クリックしてファイル選択します。
4. ファイルの解析が完了すると、テーブルが表示されます。読み込み件数はドロップゾーン内のバッジに表示されます。
5. テーブルが表示された後、検索、フィルタリング、列ソート、ページネーション、テーマの切り替えなどの操作が行えます。

## 技術仕様

| 項目 | 仕様 |
|---|---|
| 動作環境 | モダンブラウザ（Chrome / Firefox / Edge / Safari） |
| 外部依存 | なし（Google Fonts のみ） |
| ファイル構成 | `index.html` 単一ファイル |
| 文字コード | Shift_JIS（FileReader で自動変換） |
| パース処理 | Web Worker（インラインBlobWorker）による非同期実行 |
| 検索方式 | Pre-computed Search Index（パース時に一括生成、コードマッピング展開済み） |
| データ構造 | 配列×配列（`string[][]`）＋ヘッダインデックスマップ |
| 表示方式 | ページネーション（100件 / 200件 選択式） |

## 開発・カスタマイズ

このアプリケーションは純粋な HTML, CSS, JavaScript のみで作られています。  
新しいステータスコードを追加したり、表示項目を調整したい場合は、`index.html` 内の `MAPS_ACME` および `MAPS_CERT` オブジェクトを直接編集してください。  
これらのオブジェクトは Web Worker 内にも自動的に複製されるため、変更箇所は1か所のみです。
